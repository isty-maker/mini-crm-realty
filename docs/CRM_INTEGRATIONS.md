# Интеграции CRM

## Google Drive

Google Drive служит единственным хранилищем оригиналов. Сопоставление использует постоянный ID папки объекта и ID файлов. В CRM остаются метаданные: название, защищённая ссылка, время изменения и последней синхронизации. Документы не копируются в публичное хранилище и не получают публичных ссылок.

Целевой интерфейс открывает список файлов отдельно. Read-only Drive API обновляет список при открытии карточки с кэшированием и даёт сотруднику принудительно обновить перечень. Ошибка или устаревшее состояние отмечается явно. Кэш и ссылки доступны только уполномоченным сотрудникам.

JSON-паспорт импортируется с источниками, предварительной проверкой и сравнением версий. Скан служит поводом проверить паспорт. Применимость, наличие, проверка и дата документа меняются после проверки сотрудником.

## Площадки

ЦИАН и Домклик сохраняют текущие XML-маршруты и настройки выгрузки. Проверка фактической публикации — отдельный механизм. Не выводите приватные поля в экспорт и не включайте публикации побочным эффектом изменения рабочего статуса.

Авито сейчас не подключено. После проверки доступных прав аккаунта и тарифа первым этапом читаем состояния объявлений. Отдельно оцениваем автозагрузку, изменение данных, оплату и статистику. Платные операции требуют явного подтверждения владельца. Капчи не обходятся.

## Авторизованный API CRM

Целевые операции: GET списка и объекта, PATCH разрешённых полей с версией, журнал изменений, предварительный просмотр массового изменения и идемпотентность. У публикаций и расходов отдельные подтверждения. Правила доступа, версию и проверку конфликтов API использует совместно с панелью. Не возвращайте приватные данные в публичных XML, диагностике или кэше.

По команде владельца ИИ может проверить Drive, сопоставить документ с объектом, предложить изменения, применить подтверждённые данные и проверить результат. Повседневной работе CRM платный ИИ API не нужен.
