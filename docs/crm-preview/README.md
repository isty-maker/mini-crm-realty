# Превью карточки

`index.html` — отдельный статический макет, который можно открыть локально. В Django не добавлен маршрут для этого файла. Макет показывает целевые разделы на синтетических примерах и не сохраняет данные.

В `screenshots/` приведены PNG из Chromium для рабочей карточки на синтетической SQLite и для отдельного макета.
