# Проверка рабочего приложения

PNG получены из запущенной CRM через Chromium и локальный HTTPS. Использована временная SQLite с синтетическими данными из [паспорта](../examples/crm-api-passport.json). В снимках отсутствуют реальные документы, учётные данные и секреты.

- [Мобильная карточка 390 px](mobile-390.png)
- [Карточка на ПК](desktop.png)
- [Изменение характеристик на телефоне](mobile-metrics-editing.png)
- [Юридические сведения в режиме редактирования](legal-editing.png)
- [Редактирование документа](document-editing.png)
- [Подтверждение приглашения](invitation.png)

Связанный интеграционный тест запускается командой `python manage.py test crm_api.tests.test_api`.
